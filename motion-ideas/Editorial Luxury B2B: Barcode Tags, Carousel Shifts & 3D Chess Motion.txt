### 3. Programmatic Motion Specs (For Remotion / Hyperframes)

* **Vertical Carousel Item Snap (Remotion):**
```javascript
const cardIndex = Math.floor(frame / framesPerItem);
const localFrame = frame % framesPerItem;

// Snap in, hold, and slide out
const translateY = interpolate(
  localFrame,
  [0, 8, 20, 26],
  [80, 0, 0, -80],
  { extrapolateRight: "clamp", easing: Easing.out(Easing.cubic) }
);

```


* **Serif Kinetic Typography Mask:**
* Container: `overflow: hidden`.
* Text element: `translateY: interpolate(frame, [0, 10], [100, 0])` 
percent-based reveal.


* **Staggered Pill Row Physics:**
```javascript
// Stagger 3 frames per icon
const iconScale = spring({
  frame: frame - index * 3,
  fps: 30,
  config: { stiffness: 240, damping: 18 }
});

```
