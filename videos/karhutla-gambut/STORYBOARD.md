## Aturan build (untuk builder agent)

- Struktur modular: `compositions/frames/NN-*.html` per scene, mounted via `data-composition-src` (backlog #1 playbook) — hindari lint warning monolith.
- Caption karaoke: build word-timing array dari JSON (309 kata, teks dikoreksi) → active word highlight ember, pill di lower-third.
- Determinism: no Math.random (pakai seed), no repeat:-1, no getBoundingClientRect di tween-time; transform aliases GSAP saja (x/y/scale/rotation/opacity).
- Semua SFX cue = clip audio dengan `data-start` tepat di boundary shot; id unik per audio element.
- Safe zone: teks kritikal di 15–85% tinggi frame.
- Validasi: `npx hyperframes lint` → `check` → snapshot midpoint tiap scene → Studio preview → approval → render.
