# Frame — Ticker Shock

Trading-terminal data overload aesthetic for vertical market-analysis videos (Bahasa Indonesia).

## Canvas
- 1080×1920 vertical, deep navy `#061020`
- Thin neon grid + faint CSS/SVG candlestick texture background
- Persistent bottom marquee data ticker strip; terminal window chrome everywhere

## Palette
- Neon green `#00ff88` (up/good), hot red `#ff3b5c` (down/danger), amber `#ffb300` (warning/highlight)
- Panel chrome `#0c1828` borders `#1e3a5f`; text `#e6f1ff`

## Type
- Data/odometer/log lines: JetBrains Mono 400/700 (tabular nums)
- Headlines: Inter 900; shout moments Inter Black uppercase
- Captions: 56px Inter Black + mono index tags, caption-zone opted

- Order-ticket UI cards; dual-gauge verdict screens; strobe word hits
